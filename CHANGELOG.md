# Changelog

All notable project changes are documented here. This project follows Semantic Versioning.

## [1.0.1] - 2026-10-20

### Improved

- Added localized, visible breadcrumbs and matching `BreadcrumbList` structured data to the English and Persian About pages, following the portfolio → project → page hierarchy.
- Corrected the interactive app's language alternate so it no longer points to the Persian project home as if it were an app translation.
- Expanded the README with project-base-path, technical SEO, structured data, sitemap, and robots.txt notes in English and Persian.

## [1.0.0] - 2026-10-06

First tracked release of Tara GuitarLab as an interactive guitar music theory learning lab.

### Added

- Connected theory visualizations for the Circle of Fifths, scales, chords, guitar fretboard, piano keyboard, standard notation, and tablature.
- Guided lessons and practice activities for guitar music theory, note locations, scales, intervals, chords, and ear training.
- Teacher annotations that can be placed on the fretboard or piano, assigned musical roles, and played back in marking order with keyboard navigation and undo/redo.
- Computer-keyboard and MIDI note input, plus keyboard controls for keys, chords, fretboard positions, and tempo.
- Per-section visibility preferences, octave color display, and responsive full-screen views for instrument diagrams.
- Browser-based tuner and metronome, synthesized note playback, recent-playback feedback, and PDF export.

### Improved

- Reworked the app controls into a compact, keyboard-accessible toolbar with View, Key & Scale, Tools, and Shortcuts panels.
- Improved mobile layouts for the fretboard, piano, and other interactive diagrams.
- Added persistent view preferences and a reset option for app settings.
